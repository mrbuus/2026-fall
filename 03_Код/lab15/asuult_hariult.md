# Лаборатори №15 (модуль, пакет) — Асуултын хариулт

1. **`//` оператор `/` оператороос юугаараа ялгаатай вэ?**
   `/` нь үргэлж бутархай (float) хариу өгнө: `7 / 2 = 3.5`.
   `//` нь бүхэл хуваалт хийж, хариуг доош нь бүхэлчилнэ: `7 // 2 = 3`, `-7 // 2 = -4`.

2. **`__init__.py`-ийн гол зориулалт юу вэ?**
   Тухайн хавтсыг Python пакет гэж таниулна. Пакетийг импортлох үед түрүүлж ажилладаг тул
   ямар модулиудыг ачаалахыг (жишээ нь `from . import string_ops`) энд зааж болно.
   Хоосон байсан ч хавтас пакет болно.

3. **Модуль ба пакет хоёрын ялгаа?**
   Модуль нь функц, хувьсагч, класс агуулсан ганц `.py` файл.
   Пакет нь хэд хэдэн модулийг бүлэглэсэн, `__init__.py` файлтай хавтас.

4. **`from module import function` хэлбэрийг ямар үед ашиглах вэ?**
   Модулиас цөөн тооны функц хэрэгтэй бөгөөд түүнийг модулийн нэргүйгээр
   (`add(2, 3)` гэх мэт) шууд дуудахыг хүсэх үед ашиглана. Модулийг бүхэлд нь
   `import module` гэж оруулбал `module.add(2, 3)` гэж дуудна.

5. **Дахин ашиглах боломжтой кодыг хэрхэн зохион байгуулдаг вэ?**
   Нэг төрлийн үйлдлийг функц, класс болгож тусдаа модуль (`.py` файл)-д хадгална.
   Холбоотой модулиудыг пакет болгон бүлэглэнэ. Үүний дараа бусад програмаас
   `import` хийж дахин ашиглана (жишээ: энэ хавтас дахь `calculator`, `geometry_module`,
   `mypack_project`).
