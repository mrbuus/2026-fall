C ПРОГРАММ АЖИЛЛУУЛАХ — macOS / Apple Silicon

1. Терминал нээгээд төслийн хавтас руу орно:
   cd "$HOME/Desktop/Программчлалын үндэс"

2. Файлаа дугаараар сонгож ажиллуулах:
   ./run

   Эсвэл замыг шууд өгнө:
   ./run 03_Код/lab02/lab02_1a_gurvaljin_talbai.c

   Гурван тал асуухад 3 4 5 гэж бичээд Enter дарна.
   Хариу: хагас периметр 6.0000, талбай 6.0000.

3. VS Code-оос ажиллуулах:
   .c файлын таб дээр дарж идэвхжүүлээд Cmd+Shift+B дарна.
   Код хадгалагдаж, хөрвүүлэгдээд доод Terminal хэсэгт ажиллана.
   scanf-ийн өгөгдлийг тэр Terminal хэсэгт бичнэ.
   Ямар ч табаас файл сонгох: Terminal > Run Task > C: Choose file and run.
   Java Output зэрэг цонхыг идэвхжүүлсэн бол эхлээд C файлын таб дээр дарна.
   Дээд талын C/C++ гурвалжин товчийн оронд дээрх task/shortcut-ийг ашиглана.
   Ажиллаж байгаа программыг зогсоох: Ctrl+C.

4. Зөвхөн хөрвүүлэх:
   ./run --build 03_Код/lab02/lab02_1a_gurvaljin_talbai.c
   Бэлэн программыг шууд ажиллуулах:
   ./03_Код/lab02/.build/lab02_1a_gurvaljin_talbai

5. Debug хийх:
   Терминал: ./run --debug 03_Код/lab02/lab02_1a_gurvaljin_talbai.c
   LLDB дотор: breakpoint set --name main
              run
              next
              continue
              quit
   VS Code: .c файлаа идэвхжүүлж breakpoint тавиад F5 (эсвэл Fn+F5).
   C: Debug active file (LLDB) тохиргоог сонгоно.
   Debug үеийн оролт/гаралт тусдаа Terminal цонхонд харагдана.
   macOS Terminal удирдах зөвшөөрөл асуувал debug-ийн консол нээхэд хэрэгтэй.

6. Compiler-ийг шууд ашиглах жишээ (төслийн үндсэн хавтаснаас):
   clang -std=c17 -Wall -Wextra -Wpedantic -g 03_Код/lab02/lab02_1a_gurvaljin_talbai.c -o /tmp/gurvaljin -lm
   /tmp/gurvaljin

Тохиргоо: Apple Clang, C17, анхааруулгууд, debug тэмдэглэгээ, math library.
Нэг .c файлд нэг main() бүхий бие даасан дасгалыг хөрвүүлнэ.
Олон .c файлаас бүрдэх нэг программ бол clang-д шаардлагатай файлуудаа хамтад нь өгнө.
Шинэ .c файлыг 03_Код дотор хадгалахад ./run жагсаалтад автоматаар орно.
Бусад хавтас дахь файлыг замаар нь өгч болно; зайтай замыг "..." дотор бичнэ.
Программ өөрийн .c файл байгаа хавтсаас ажиллана (харьцангуй файлын замд хамаарна).
Үүссэн executable нь эх кодын хажуугийн .build хавтаст хадгалагдана.
Хөрвүүлэлт алдаатай бол өмнөх executable-ийг ажиллуулахгүй.

VS Code-ийн албан ёсны Clang/LLDB заавар:
https://code.visualstudio.com/docs/cpp/config-clang-mac
